## Fixed Structure

The generated property must preserve the Vine structure:

1. Optional feed-backed promo strip and popdown.
2. Mobile header with property name, call icon/link, `Tour` button, and hamburger menu.
3. Full-height mobile hero where promo + nav + hero fill the viewport.
4. Linked review row only when sourced; fractional star fill when rating is not whole.
5. Official shared `Live Better. Live Easy.` SVG visual from the package, with `title_text` used only as the accessible label and no edge-added TM.
6. Bedroom/city headline.
7. White `Find Your Home` CTA.
8. First native-sourced content block.
9. Award/badge in the exact native/proven sequence when sourced.
10. Second native-sourced content block.
11. Lazy native continuation with shell-owned sections hidden so they do not repeat.
12. Compact shared consent widget.

Desktop remains native pass-through. No desktop topper, desktop shell, desktop hero asset, or desktop visual rewrite is allowed without explicit current approval.

## Data-Only Fields

Only these may vary by property:

- Property name, code, address, city/state, URLs, CTA hrefs.
- Feed-backed special text and presence.
- Brand color tokens captured from native computed styles.
- Official font tokens/assets when available.
- Mobile hero and first two block images, after canonical optimization and byte-budget proof.
- First two native content blocks, including copy, bullets, CTA labels, awards, and hidden-media behavior.
- Review rating, count, link, and presence.
- Source-attributed phone lookup, defaulting to VWS.
- GA4, Heap, Ahrefs existing project, Resi bridge, Cloudflare analytics, GSC, Captain/Data Pond evidence IDs.
- `llms.txt`, meta, OG, canonical, and schema values.

No other structure, class behavior, script ownership, loading strategy, or component order may vary.
