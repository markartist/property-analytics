# Venterra Brand Color Standard

Date: 2026-05-23
Source: `/Users/mark/Downloads/New Branding Colors_Named 2.pdf`

## Rule

For new or materially updated user-facing UI, reports, decks, documents, charts, and generated assets, use only the official Venterra palette below unless the user explicitly specifies otherwise in the current task.

Existing legacy surfaces may still contain older colors. Do not turn a small task into a broad redesign without approval, but any touched visual element, color picker, swatch list, or new configurable color should be aligned to this palette.

## Discontinued Colors

Galliano `#EAAB00` is discontinued and should not appear in new color palettes, swatch controls, or configurable color defaults. If a touched surface still contains Galliano as a configurable/default color, replace it with an active palette color.

## Initial Application

The Edge Messages admin color swatches now use this official palette plus black and white. Default adjustable colors for the transparent-pricing proofs were also normalized to official colors.
