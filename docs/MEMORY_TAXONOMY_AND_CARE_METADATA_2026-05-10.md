# Memory Taxonomy And Care Metadata

Date: 05/10/2026

## Memory Classes

- evidence_memory
- working_memory
- property_memory
- human_submitted_memory
- agent_self_note
- commitment_memory
- relationship_context
- regional_awareness
- communal_pattern
- doctrine_candidate
- doctrine
- archived_memory

## Lifecycle States

Raw input can become parsed claim, candidate, working memory, verified context, report-eligible context, doctrine candidate, approved doctrine, archived, expired, rejected, or superseded. Invalid transitions are blocked.

## Care Metadata

Every memory item carries care metadata:

- do_not_overstate
- ask_before_public_use
- avoid_person_judgment
- temporary_context
- sensitive_context
- share_as_pattern_only
- requires_human_review
- preferred_tone
- correction_allowed_by_roles

Care metadata controls how memory may be used, shown, summarized, and archived. It also keeps uncertainty visible.

## Allowed Uses

Allowed uses include Captain reasoning, Expert Read context, Navigator review, Quartermaster review, product readiness review, Fleet summary, regional summary, Scribe input, public copy, report publication, historical review, and self reminder.

Self notes cannot be public copy or report publication evidence. Human-submitted memory cannot become public copy while verification is required. Relationship context cannot become performance scoring or publication evidence.
