Match Methodology

Matched-Pairs Design: Each Resi property matched with 2 portfolio properties using weighted similarity scoring to control for confounding variables:

  • Metro Match (40 pts): Same metro area (10 pts if different) — controls for market dynamics
  • Unit Similarity (30 pts): ±25% units = 30 pts, ±35% = 20 pts, ±50% = 10 pts — controls for property size
  • Traffic Similarity (20 pts): Based on 15-day session volume proximity — controls for audience size
  • GBP Proxy (10 pts): Presence of verified GBP data — controls for local presence

Exclusions: All Resi properties excluded from portfolio match pool. Monteverde (pre-opening) explicitly excluded.

Comparison Period: 15-day window (Jan 12-24) with 87% data coverage (13/15 days). Collection outage Jan 25-27 does not affect analysis.

Data Sources & Methodology

  • Google Search Console (GSC): 15-day impressions and clicks (11/12 days with 3-day API lag)
  • Google Analytics 4 (GA4): 15-day sessions and engagement rates (13/15 days, 87% coverage)
  • PageSpeed Insights (PSI): Mobile performance scores and Core Web Vitals (11/13 days, 85% coverage)
  • Google Business Profile (GBP): Local engagement actions (13/15 days, 87% coverage)
  • Contact Intent Rate (CIR): Calculated from ga4_event_facts table using event mapping:
    • Resi events: resi_price_quote, resi_application_start, resi_apt_tour_click
    • Portfolio events: pricequote_click, applyonline_click, scheduletour_click
    Phone clicks and direction requests excluded to ensure apples-to-apples comparison.

Data Caveats & Collection Notes

  • Collection Period: 15-day analysis window (Jan 12-24, 2026) chosen for complete data coverage. Collection outage Jan 25-27 does not affect analysis (87% coverage achieved).
  • CIR Normalization: Resi and Portfolio use different event names for same actions. Event mapping ensures valid comparison (tour/apply/quote only).
  • GSC Coverage: 11/12 days (92%) due to 3-day API lag. Expected behavior, not a data quality issue.
  • Match Pool: 87 portfolio properties available after excluding all 4 Resi properties (including pre-opening Monteverde).
  • Engagement Rate: Calculated as (engaged_sessions / total_sessions) × 100.
  • GTMetrix: Not collected or used in this analysis.
