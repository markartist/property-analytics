Executive Summary

This report evaluates three operational Resi-hosted properties against matched portfolio properties to assess relative performance across five key categories: Demand/Visibility, Engagement, Intent/Conversion, Performance/UX, and Trust Context.

Key Findings:
  • Camber Ridge: Portfolio wins decisively (3/5 categories) — portfolio matches show stronger demand visibility (+53% impressions), higher engagement (+10.0 pts), and better technical performance (PSI 62 vs 54)
  • The Delta Pearland: Mixed results — Resi wins demand (+161% impressions, +193% clicks) and engagement (+6.5 pts), but portfolio wins performance (PSI 63 vs 37)
  • Cendana District West: Mixed results leaning portfolio — portfolio matches show +96% impressions and marginally better performance
⚠️ Data Limitations: Intent/Conversion metrics are unavailable due to GA4 conversion tracking issues (all properties show 0 conversions). Trust Context (GBP) data is too limited for meaningful comparison. Performance assessments are based on Demand, Engagement, and Technical Performance only.

Match Methodology

Each Resi property was matched with two portfolio properties using a weighted scoring algorithm:

  • Metro Match (40 pts): Same metro area (10 pts if different)
  • Unit Similarity (30 pts): ±25% units = 30 pts, ±35% = 20 pts, ±50% = 10 pts
  • Traffic Similarity (20 pts): Based on 30-day session volume proximity
  • GBP Proxy (10 pts): Presence of verified GBP data

Exclusions: All Resi properties were excluded from the portfolio match pool. Monteverde (pre-opening Resi property) was also excluded.
